# Как помочь проекту

- Ложная тревога или пропущенная проблема — issue с выводом `node-guard --force --quiet`
  (адреса можно заменить на 203.0.113.x) и конфигом без токенов.
- Код: Python 3.9+, только стандартная библиотека; сторожа не должны ничего менять в панели —
  PR с PATCH/POST/DELETE к панели не принимаются. Перед PR: `python3 -m py_compile *.py`, `bash -n scripts/*.sh`.
